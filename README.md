# 一、项目背景

1. **目标**：使用自定义数据集训练一个实例检测与分割模型，用于将【目标】从其背景及周围环境中分离出来。该模型通过在 ultralytics 提供的 YOLOv8 分割模型上对自定义数据集进行训练构建而成。
2. **数据选择**：我选择用于训练和测试该模型的数据集是 Ayoola Olafenwa 的“Nature”数据集的修改版本，该数据集可在此处作为 PixelLib 项目的一部分获取。该数据集共包含 400 张高质量的【目标】图像，已进行实例分割标注，分为 300 张用于训练和 100 张用于测试。这些图像最初使用 LabelMe JSON 格式进行标注，但 YOLO 采用不同的标注格式，因此使用名为 labelme2yolo 的工具将该数据集转换为 YOLO 可训练的格式和文件结构。
