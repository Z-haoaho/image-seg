# 一、项目背景

1. **目标**：使用自定义数据集训练一个实例检测与分割模型，用于将【目标】从其背景及周围环境中分离出来。该模型通过在 ultralytics 提供的 YOLOv8 分割模型上对自定义数据集进行训练构建而成。
2. **数据选择**：我选择用于训练和测试该模型的数据集是 Ayoola Olafenwa 的“Nature”数据集的修改版本，该数据集可在此处作为 PixelLib 项目的一部分获取。该数据集共包含 400 张高质量的【目标】图像，已进行实例分割标注，分为 300 张用于训练和 100 张用于测试。这些图像最初使用 LabelMe JSON 格式进行标注，但 YOLO 采用不同的标注格式，因此使用名为 labelme2yolo 的工具将该数据集转换为 YOLO 可训练的格式和文件结构。

## 2.1 数据标注（LabelMe）

### 2.1.1 标注环境

统一标注环境版本

| 组件 | 版本 | 备注 |
| --- | --- | --- |
| Labelme | ≥ 4.5.7 | 支持关键点标注 |
| PyQt5 | 5.15.4 | 图像界面基础 |
| OpenCV | 4.5.4 | 图像处理核心 |

### 2.1.2 标注规范

1. 目标框标注原则：
   - 框体紧贴物体边缘（留白不超过 3 像素）
   - 遮挡物体按可见部分标注
   - 小物体（< 32×32 像素）建议放大标注
2. 关键点标注原则：
   - 关键点必须归属到对应检测框内
   - 可见点标注实际位置（即使被轻微遮挡）
   - 完全不可见点标记为“未标注”状态
   - 对称关键点需保持左右一致性

### 2.1.3 标注前的统一处理

1. 统一缩放至相同最大边长（保持比例）
2. 生成缩略图用于快速标注（原始图用于最终训练）
3. 自动校正 EXIF 方向信息

### 2.1.4 标注质量验证

1. 关键点超出物体边界框
2. 重叠框体未处理
3. 标签命名不一致
4. 图像尺寸与标注坐标不匹配

## 2.2 格式转换与数据集划分

Labelme 格式转 COCO 格式

数据集划分：

1. 保持各类别在划分集中的分布均衡
2. 同一场景的图像不应分散在不同集合
3. 划分数据集时使用分层抽样

## 2.3 常见训练问题的标注质量诊断

| 现象 | 可能原因 | 解决方案 |
| --- | --- | --- |
| 关键点预测偏移 | 标注不一致 | 重新统一标注标准 |
| 漏检小物体 | 标注不完整 | 增强小物体标注 |
| 误检率高 | 负样本不足 | 添加困难样本 |
| 关键点混淆 | 标签错误 | 检查关键点映射 |

做法：

- 随机抽查 10% 的标注图像
- 统计关键点可见性分布
- 验证标注框宽高比分布
- 检查边缘案例的处理一致性
